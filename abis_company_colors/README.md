# abis_company_colors — Couleurs d'entreprise

> Module Odoo 19.0 — configure les couleurs corporate de ta société et
> propage-les automatiquement sur le portail, les emails et les rapports.

## Fonctionnalités

- 3 couleurs configurables par compagnie : principale, secondaire, accentuation
- Widget `color` natif Odoo dans les paramètres
- Validation HEX (`#abc` ou `#714B67`)
- CSS dynamique servi sur `/abis_colors/<company_id>.css`
- Cache HTTP 1h, aucun appel externe
- Multi-compagnies, fallback aux couleurs Odoo par défaut si désactivé

## Installation

1. Va dans **Apps**, recherche "Couleurs d'entreprise"
2. Installe
3. Ouvre **Paramètres → Sociétés**, choisis ta société, onglet "Couleurs corporate"
4. Définis tes 3 couleurs, sauve

## Configuration

Disponible aussi depuis **Paramètres généraux → Sociétés → Couleurs corporate**.
