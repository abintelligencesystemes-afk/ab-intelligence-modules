AB Intelligence — Grow Marketing

Pilotage éditorial multi-canal + vidéo IA low-cost.

Workflow complet idée → brouillon → validation → planning → publication

Génère, valide, programme et publie tes posts sur LinkedIn, Instagram, Facebook, X / Twitter, YouTube, Threads et TikTok directement depuis Odoo. Alimenté par Anthony Growth Agent (OpenAI GPT-4o-mini par défaut).

Génération vidéo MP4 intégrée — low-cost

Module unique sur le marché Odoo : produire une vidéo verticale 9:16 prête pour TikTok / Reels / Shorts depuis un script, avec voix off, sous-titres burnés et montage automatique. Stack 100 % low-cost :

  • OpenAI TTS (voix nova, alloy, echo, fable, onyx, shimmer) — environ 0,014 € par 1000 caractères.
  • OpenAI Whisper pour la transcription en SRT — environ 0,0055 € par minute.
  • FFmpeg en subprocess (gratuit, open-source).

Coût visé : ~0,05 € par vidéo. Toute la stack est échangeable (ElevenLabs, Runway, Sora prévus en V0.3).

Fonctionnalités V0.2

  • abrmd.grow.idea — file d'idées avec workflow proposed → approved → used / rejected.
  • Cron quotidien (07h UTC) qui propose 3 idées chaque matin à partir des top patterns marketing et d'un produit / projet.
  • abrmd.grow.post — limites de caractères par canal, régénération de brouillon en 1 clic, tracking URL + date publication.
  • abrmd.grow.media — bibliothèque images / vidéos avec import iCloud Drive (self-hosted) ou upload manuel.
  • abrmd.grow.pattern + abrmd.grow.veille.video — patterns marketing avec score composite engagement × récence.
  • Vues complètes : kanban, list, form, calendar, gallery, search avec filtres et group-by riches.
  • Bouton "Générer post Grow" sur produits et tâches projet.
  • Wizard de génération IA avec 3 propositions cliquables.
  • Wizard de génération vidéo MP4 avec preview coût en temps réel.

Modes de déploiement

  • Module Python on-premise — tout natif (FFmpeg via subprocess sur l'hôte Odoo). Idéal pour les PME qui auto-hébergent.
  • Odoo SaaS / Online — module Python non installable par Odoo (limitation plateforme). Mode hybride avec agent local (script Python standalone qui appelle FFmpeg côté client et upload le MP4 via ir.attachment). Documentation complète dans le README.

Conformité & sécurité

  • RGPD : aucune FK obligatoire vers res.users / res.partner.
  • Kill switch local + distant via ir.config_parameter.
  • Clés API stockées dans ir.config_parameter (jamais en clair).
  • Aucune publication automatique — l'humain valide toujours.
  • Telemetry RGPD-safe : UUID instance + compteurs anonymes uniquement, jamais de contenu de post.
  • Tests pure-python (28+ verts) couvrant manifest, security, hooks, anti-secret, pipeline vidéo, char limits, workflows.
