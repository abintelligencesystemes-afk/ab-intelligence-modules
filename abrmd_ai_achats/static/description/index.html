OCR Factures Fournisseurs nouvelle génération

Bypass IAP + Apprentissage progressif = -90 % de coût en 3 mois

Pourquoi ce module ?

  • Remplace account_invoice_extract (crédits IAP 0,10 €/facture)
  • OCR via OpenAI Vision (gpt-4o) avec prompt JSON strict
  • Coût : 0,015 € par facture au démarrage, 0,002 € après 3 mois d'apprentissage
  • 3 référentiels d'apprentissage : cache hash, signatures fournisseurs, matching produits
  • Bouton « Corriger & Apprendre » qui enrichit le référentiel à chaque correction
  • Sécurisé : License JWT vérifiée à chaque appel, pas de stockage du PDF côté serveur

Comment ça marche

  1. Tu glisses un PDF/image dans la pièce jointe d'une facture fournisseur brouillon
  2. Clic « OCR via OpenAI » → extraction JSON + pré-remplissage du brouillon
  3. Tu corriges si besoin, clic « Corriger & Apprendre »
  4. À la facture suivante du même fournisseur, le module reconnaît tout : produits, prix, format
  5. Au fil du temps, l'IA n'est plus appelée que pour les nouveaux formats

Architecture

Le module communique uniquement avec le Worker AB Intelligence. La clé OpenAI n'est jamais exposée à l'instance Odoo.
