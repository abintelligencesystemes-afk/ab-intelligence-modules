AI RGPD — Conformité complète RGPD pour Odoo 19

6 piliers RGPD directement intégrés à ton Odoo : registre Article 30, consentements, droits des personnes, anonymisation, logs d'accès et dashboard DPO. Module pur Odoo 19, licence LGPL-3 — gratuit. Conçu par AB Intelligence Systèmes pour les PME et indépendants soumis au RGPD.

Les 6 piliers

  1. Registre Art.30 — modèle dédié avec finalité, base légale (6 bases), catégories de données, destinataires, transferts hors UE, conservation, sécurité. 3 entrées prêtes à l'emploi (CRM, Comptabilité, RH).
  2. Consentements — capture, retrait, expiration auto. Hash SHA-256 + sel par tenant. Workflow given → withdrawn → expired. Cron quotidien.
  3. Droits des personnes (Art.12-22) — workflow demande complet avec délais légaux calculés (1 mois + 2 mois prolongation). 7 types couverts : accès, rectification, effacement, limitation, portabilité, opposition, décision automatisée. Alerte auto à J-7.
  4. Anonymisation et pseudonymisation — Server Actions sur res.partner. Mode réversible (hash + sel) ou irréversible (Art.17). Helpers email, téléphone, IP.
  5. Logs d'accès — modèle dédié + API log_access() appelable depuis n'importe quel modèle. 10 types d'opérations tracés. Cron de purge auto.
  6. Dashboard DPO — 10 KPIs en temps réel. Alertes contextuelles (demandes en retard, échéances à 7 jours, contact DPO non configuré, registre vide).

Pourquoi ce module ?

  • Indépendant — pas de SaaS, pas de call-home obligatoire, ton Odoo reste maître de ses données
  • Préconfiguré — 3 traitements types prêts à l'emploi (CRM, Compta, RH) alignés CNIL + Code de commerce + Code du travail
  • Démontrable — chaque action laisse un log horodaté, prêt à présenter en audit CNIL
  • Gratuit — LGPL-3, sources publiques, contributions bienvenues

Compatibilité

Odoo 19 Community + Enterprise · dépendances standards (base, mail, mail_activity) · 100% stdlib Python · 12 tests TransactionCase + 13 tests pure-python.

Démarrage en 5 minutes

  1. Installer "AI RGPD" depuis Apps
  2. Aller dans Paramètres → AI RGPD → Renseigner DPO + sel d'anonymisation
  3. Vérifier le Registre Art.30 (3 entrées par défaut)
  4. Ouvrir le Dashboard DPO et vérifier que les alertes sont vertes
  5. Activer base.automation pour tracer les accès aux modèles sensibles
